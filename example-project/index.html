Проєкт на GDevelop: Click Tycoon 🪙

Огляд проєкту 📜

Цей проєкт демонструє можливості GDevelop через створення класичної гри жанру "Клікер" або "Tycoon". Гравець розпочинає з простого клікання, щоб заробити початковий ресурс, а потім використовує його для придбання покращень та автоматичних джерел доходу, будуючи власну віртуальну імперію.

Мета проєкту:

Створити захопливу та затягуючу гру "Click Tycoon" з глибокою системою прогресії та покращень за допомогою візуального програмування на GDevelop.

Основні завдання:

  • Реалізація механіки клікання для заробітку ресурсу.
  • Додавання системи придбання покращень, що збільшують дохід від клікання.
  • Побудова логіки автоматичного заробітку (пасивний дохід) від придбаних об'єктів/бізнесів.

Технічна реалізація ⚙️

Використані технології:

  • GDevelop для створення гри
  • Подієве візуальне програмування
  • Змінні для ресурсів, цін, доходу

Інноваційні аспекти: 💰

  • Система різноманітних покращень з експоненційним зростанням доходу.
  • Візуалізація придбаних об'єктів або "імперії" гравця.
  • Звукові ефекти при кліканні та придбанні покращень.

Особливості проєкту ✨

  • Простий, але затягуючий ігровий процес.
  • Інтуїтивно зрозумілий інтерфейс.
  • Можливість грати як активно (клікаючи), так і пасивно (завдяки автоматизації).
  • Система глибокої прогресії та розвитку.

Керування 🖱️

  • Ліва кнопка миші/Дотик — основна дія (клікання для заробітку, взаємодія з UI)
  • Інші клавіші можуть бути використані для доступу до меню або функцій (наприклад, збереження, налаштування).
